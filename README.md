### Module Objectives
- Understand Artificial Intelligence, Machine Learning and Deep Learning.
- Learn Python programming fundamentals.
- Practice loops, functions and data structures.

1. Introduction to AI, ML and Deep Learning.
2. Python variables, data types and operators.
3. Conditional statements and loops.
4. Functions and lists.
5. Strings, tuples, sets and dictionaries.
6. Exception handling and debugging.
